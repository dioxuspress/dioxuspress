# 在线支付与打赏集成

默认完整档位（`payments` Cargo feature）内置了基于纯 Rust 密码学验签的微信支付 v3 与支付宝当面付/电脑网站支付网关，无需额外部署中转计费服务。

## 核心业务闭环

1. **防重下单与幂等状态机**：订单表严格遵循 `Pending -> Paid -> Fulfilled` 单向状态跃迁；
2. **严格非对称签名校验**：所有 `/api/pay/notify/*` 异步通知均在服务端验证平台公钥签名与订单金额一致性，杜绝伪造回调；
3. **自动履约发货**：验签通过后在同一数据库事务内更新订单状态并写入用户课程或 Pro 会员权益，学员刷新课节页面即可解锁全文；
4. **文章与播客打赏（`TipJar`）**：开启 `payments` 特性时，博客文章与播客详情页自动展示轻量打赏卡片；若编译 `basic` / `accounts` / `course` 档位则相关支付路由与组件全部在编译期剥离。
