# DioxusPress Blog Starter

基于 [DioxusPress](https://dioxuspress.dev)（`blog` 极简技术博客 / 数字花园预设）构建的零数据库写作仓库。

## 特性亮点

- **极简阅读流（`minimal` 布局）**：收起冗余模块入口，搭配 `coffee` 暖羊皮纸与深咖护眼双模配色。
- **硬核写作原语**：原生支持服务端 LaTeX → MathML 数学公式、`:::code-tabs` 多语言代码对比与 Mermaid 图表。
- **一等公民 RSS 订阅**：自动生成 `/feed.xml` Atom 订阅源与 `authors.yml` 多作者署名。

## 快速启动

```bash
dioxuspress check
docker compose up -d
```

打开浏览器访问 <http://localhost:8080>。
